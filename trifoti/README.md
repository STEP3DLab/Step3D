# ТРИФОТИ / Art & Space

Самостоятельный сайт творческой студии в отдельной ветке `trifoti-studio`. Основной Step3D не изменяется.

## Запуск

Из корня репозитория:

```sh
node trifoti/server.cjs
```

Откройте http://127.0.0.1:4173. Сборка и установка зависимостей не нужны. В локальной рабочей папке сайта этот же сервер использует каталог `dist`.

Для статического хостинга загрузите содержимое папки `trifoti` на любой HTTP(S)-хостинг. Условия использования GitHub Pages для основного Step3D не изменены. Запуск `index.html` через `file://` не поддерживается браузерными ES-модулями.

## Сайт

- Контрастная композиция: тёмный интерактивный ателье, светлый арт-каталог, зелёные акценты, крупная типографика.
- Три WebGL-сцены: архитектурный павильон из 31 ребра, пластическая лента и модель Polar Sage из Step3D.
- Вращение перетаскиванием, плавная инерция, три материала, студийное освещение, мягкие тени, полноэкранный режим, деконструкция и сброс ракурса.
- Клавиши стрелок вращают объект; + и − меняют масштаб, 0 сбрасывает ракурс. Ctrl + колесо также меняет масштаб.
- 24 работы с фильтрами и полноразмерным просмотром; фотографии скульптуры, интерьеров, живописи и эскизов из папки пользователя.
- Адаптивная версия, клавиатурная навигация, reduced motion и запасное изображение при отсутствии WebGL.
- Шрифты, 3D-библиотека и все изображения хранятся локально; внешние CDN не требуются.

Бриф скачивается локально, данные не отправляются. Для приёма заявок необходимо подключить реальные контакты студии. Email и телефон не выдумывались.
